01 / ABOUT

기술과 경험의 다음 장면

XR 기술과 개발을 바탕으로 몰입형 인터랙션, 공간 컴퓨팅, 현실과 디지털 경험이 만나는 새로운 사용 경험을 탐구합니다.

Immersive Interaction몰입감 있는 상호작용
Spatial Computing공간과 디지털 정보의 연결
Human Experience사람 중심의 XR 경험

XR은 VR·AR·MR을 아우르는 확장 현실의 스펙트럼입니다.

WebXR은 웹에서 몰입형 하드웨어와 상호작용하는 표준 API를 제공합니다.

XR 세션은 인라인, 몰입형 VR, 몰입형 AR 모드로 나뉩니다.

3DoF는 회전 중심, 6DoF는 회전과 이동을 함께 추적합니다.

공간 트래킹은 가상 콘텐츠를 사용자의 움직임과 맞춥니다.

실제 크기와 주변 환경을 고려해야 몰입감과 편안함을 유지할 수 있습니다.

XR 입력에는 손, 컨트롤러, 시선과 같은 다양한 입력원이 포함됩니다.

핸드 인풋은 관절 포즈를 추적해 자연스러운 인터랙션을 가능하게 합니다.

안전한 XR 경험에는 사용자의 동의와 개인정보 보호가 필요합니다.

기기별 지원 기능을 확인한 뒤 경험을 시작하는 흐름이 중요합니다.

참고: W3C WebXR Device API · MDN WebXR

02 / EXPERIENCE

XR Development

CURRENT FOCUS

XR 기술 연구와 개발

새로운 인터랙션과 몰입형 경험을 만들기 위한 기술과 사용성을 탐구합니다.

Spatial Interaction공간 트래킹과 손·컨트롤러 입력
Immersive WebWebXR·OpenXR 기반의 확장 가능한 경험
Comfortable UX편안하고 안전한 몰입형 사용자 경험

먼저 브라우저와 기기가 원하는 XR 세션을 지원하는지 확인합니다.

사용자 동작 뒤에 세션을 요청해 예기치 않은 센서 접근을 줄입니다.

세션이 시작되면 프레임 루프에서 포즈와 입력을 읽습니다.

참조 공간은 뷰어·로컬·바운디드 환경의 좌표 기준을 정의합니다.

렌더링은 WebXR이 제공하는 타이밍에 맞춰 안정적으로 수행합니다.

WebXR은 장면 렌더러가 아니므로 3D 모델과 재질은 별도로 구성합니다.

OpenXR은 여러 런타임과 장치의 입력 프로필을 연결하는 기준을 제공합니다.

손과 컨트롤러 입력은 동일한 상호작용 의도에 매핑할 수 있어야 합니다.

권한, 보안 컨텍스트, 사용자 동의를 기능 설계에 포함합니다.

지원되지 않는 기능에는 평면 화면이나 대체 입력을 제공해야 합니다.

참고: Khronos OpenXR Registry · W3C Hand Input

What I explore

XR TechnologyWebXR·OpenXR, 공간 트래킹, 디스플레이와 입력 장치를 연결하는 기반 기술
XR Development실시간 3D 렌더링과 손·컨트롤러 입력을 활용해 실행 가능한 XR 경험을 구현
Interactive Experience자연스러운 인터랙션, 편안한 움직임, 접근성을 고려한 몰입형 사용자 경험 설계

XR Technology는 현실과 가상 정보를 같은 공간에서 다루는 기반 기술입니다.

XR Development는 세션, 입력, 렌더링을 하나의 실행 흐름으로 연결합니다.

Interactive Experience는 기술보다 사용자의 행동과 피드백을 먼저 봅니다.

공간 앵커와 참조 공간은 콘텐츠가 환경에 붙어 보이도록 돕습니다.

손 추적은 버튼을 찾지 않아도 되는 직접적인 상호작용을 탐구하게 합니다.

컨트롤러 프로필은 장치마다 다른 버튼과 포즈를 일관된 액션으로 바꿉니다.

시야, 이동 속도와 가속은 멀미와 피로에 영향을 줄 수 있습니다.

짧은 피드백과 명확한 상태 표현은 몰입 중에도 사용성을 높입니다.

접근성은 시각·청각·운동 특성이 다른 사용자를 함께 고려하는 과정입니다.

웹 기반 XR은 링크로 공유하고 기기 지원 여부에 따라 경험을 조정할 수 있습니다.

참고: WebXR fundamentals
